# Changelog

## 1.0.0

- Added persistent Saved Devices with MAC-first identity and automatic IP refresh.
- Added secure, versioned XML import and XML, CSV, and HTML export.
- Added SSH, FTP, HTTP, HTTPS, SMB, and RDP service detection and last-seen data.
- Added result/favorites tabs, scan profiles, `/24` selection, alternating rows,
  dependency checks, and original application artwork.
- Added Wake-on-LAN across all active broadcast interfaces.
- Added confirmed, non-interactive SSH shutdown, reboot, cancellation, and
  per-host outcomes without storing passwords.
- Removed telemetry and obsolete telemetry preferences.
- Hardened opener substitution against shell injection and replacement errors.
- Added a Debian-managed OpenJDK 21 runtime dependency and install/start/remove smoke tests.
